MaixCAM2 receiver for CPython 3.13 x64

First run:
  Double-click install_and_run.bat

Later runs:
  Double-click run.bat

If an older or broken environment remains:
  Double-click reset_environment.bat, then install_and_run.bat

The installer uses a separate .venv313 folder and does not modify your global
Python packages. It installs binary wheels only; no C/C++ compiler or separate
FFmpeg installation is required when the official wheels install normally.
